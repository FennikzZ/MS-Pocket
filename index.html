ถ้าชื่อในช่อง "ผู้รับ" ของสลิปตรงกับชื่อนี้ แอปจะบันทึกเป็นรายรับให้อัตโนมัติ คั่นหลายชื่อด้วยจุลภาค

การนำเข้าสลิป
สำรองข้อมูล
ดึงสลิปอัตโนมัติด้วย Shortcuts

แบบที่ 1: เกือบ real time ทุกครั้งที่ปิดแอปธนาคาร iPhone จะอ่านสลิปล่าสุดเก็บสะสมไว้ในไฟล์ให้เอง

  1. เปิดแอปธนาคารแต่ละแอป เปิดตั้งค่า บันทึกสลิปอัตโนมัติ ลงคลังรูป
  2. แอป คำสั่งลัด → แท็บ ระบบอัตโนมัติ → + → แอป → เลือกแอปธนาคารทั้งหมด → ติ๊ก ถูกปิด → เรียกใช้ทันที
  3. ใส่คำสั่ง: ค้นหารูปภาพ ตัวกรอง วันที่ถูกเพิ่ม อยู่ใน 15 นาทีล่าสุด
  4. ทำซ้ำกับแต่ละรายการ → ข้างในใส่ แยกข้อความจากภาพ → ข้อความ พิมพ์ ##### ขึ้นบรรทัดใหม่ แทรก ข้อความจากภาพ → เพิ่มไปยังไฟล์ข้อความ (Append to Text File) ไฟล์ Shortcuts/slips.txt
  5. เวลาจะดูยอด เปิดแอปนี้ → 📋 นำเข้าข้อความ → เลือกไฟล์ .txt → slips.txt สลิปที่บันทึกแล้วจะถูกข้ามเอง เลือกไฟล์เดิมซ้ำได้เรื่อยๆ

แบบที่ 2: ดึงทีละวัน ให้ iPhone อ่านสลิปใหม่จากอัลบั้มของแอปธนาคารให้เอง (ใช้ Live Text ของ iPhone ซึ่งแม่นกว่า) แล้วคัดลอกไว้

  1. เปิดแอป คำสั่งลัด (Shortcuts) → กด + สร้างคำสั่งใหม่ ตั้งชื่อ "ดึงสลิป"
  2. เพิ่ม ค้นหารูปภาพ (Find Photos) → เพิ่มตัวกรอง อัลบั้ม = อัลบั้มของธนาคาร (เช่น K PLUS, SCB EASY) และ วันที่ถูกเพิ่ม อยู่ใน 1 วันล่าสุด
  3. เพิ่ม ทำซ้ำกับแต่ละรายการ (Repeat with Each) แล้วใส่ข้างในว่า แยกข้อความจากภาพ (Extract Text from Image) ตามด้วย ข้อความ (Text) ที่พิมพ์ว่า ##### ขึ้นบรรทัดใหม่ แล้วแทรกตัวแปร ข้อความจากภาพ
  4. หลังจบลูป เพิ่ม รวมข้อความ (Combine Text) → คัดลอกไปยังคลิปบอร์ด (Copy to Clipboard)
  5. (ถ้าต้องการให้ทำเอง) แท็บ ระบบอัตโนมัติ → เวลาของวัน เช่น ทุกวัน 21:00 → เรียกคำสั่ง "ดึงสลิป" → เลือก เรียกใช้ทันที
  6. เปิดแอปนี้ กด 📋 นำเข้าข้อความ → วางจากคลิปบอร์ด
