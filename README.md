# MS-Pocket

เว็บแอป (PWA) บันทึกรายรับรายจ่ายสำหรับ iPhone พร้อมอ่านสลิปโอนเงิน

- ข้อมูลทั้งหมดเก็บในเครื่องผู้ใช้ (localStorage) ไม่มีการส่งขึ้นเซิร์ฟเวอร์
- อ่านสลิปในเครื่องด้วย Tesseract.js หรือนำเข้าข้อความจาก Live Text ผ่าน Shortcuts
- เปิดผ่าน GitHub Pages แล้วกด "เพิ่มไปยังหน้าจอโฮม" ใน Safari
